# Packet Capture & Parser for IDS

Hệ thống tìm kiếm, phát hiện và ngăn chặn xâm nhập.

## Mục tiêu

Xây dựng module Packet Capture & Parser bằng Python cho hệ thống IDS.

## Chức năng dự kiến

- Live packet capture
- PCAP import
- IPv4 parsing
- TCP parsing
- UDP parsing
- HTTP/1.x parsing
- DNS parsing
- SMTP parsing
- Normalized IDS Event
- JSON Lines output
